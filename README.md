# AccuKnox Security Dashboard

A responsive cloud security dashboard built with React and Vite.

## Features

- Dark and light themes with preference persistence
- Date-range filtering for dashboard charts
- Add and remove widgets, with Undo support
- Search and add existing widgets by category
- Create custom widgets with a name, description, and category
- Notification panel with mark-all-as-read functionality
- Sidebar navigation and category filtering
- Persistent dashboard state

## Tech Stack

- React
- Vite
- Zustand
- Recharts
- Lucide React

## Prerequisites

- Node.js
- npm

## Installation

Clone or download this repository, then open a terminal in the frontend project directory.

```bash
npm install
```

## Run Locally

```bash
npm run dev
```

Open the local URL printed in the terminal.

## Production Build

```bash
npm run build
```

Vite generates the production build in the `dist` directory.

## Notes

This project uses sample dashboard data for demonstration purposes.
